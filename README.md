# «Тёмная луна» — Telegram-бот детективной ролевой игры

Бот для настольно-ролевой детективной игры на 10–15 игроков: раздача ролей,
QR-улики, двухфазное голосование и автоматический выбор финала.

## Что умеет

- раздача ролей игрокам с сохранением тайны;
- генерация QR-кодов улик (`generate_qr.py`);
- двухфазное голосование с обработкой всех исходов;
- финал выбирается автоматически по набранным голосам.

## Структура

`handlers.py`, `game_logic.py`, `database.py` (SQLite), `data.py` — данные игры,
`PLAN.md` — план разработки v4.3, `DARK_MOON_v4.3.md` — правила,
`vps_setup.py` / `vps_ssh.py` — выкладка на VPS, `tests/` — тесты.

## Стек

Python, aiogram, SQLite, qrcode.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env
python main.py
```
